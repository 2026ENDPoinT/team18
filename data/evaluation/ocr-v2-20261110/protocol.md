# 사전 고정 평가 규칙 (OCR 실행 전 작성)

- 대상 커밋: `46e777ed1a1e180188c0f2ff17384fd58932a780`, 브랜치 `ocr_test`.
- `ai/local/ocr.py`의 `LocalOCR('local')` 기본값을 그대로 사용한다. `orientation=auto`, `layout=rows`, `crop_padding=0`. 검출·회전 선택·줄 인식을 모두 포함한다. Gemini나 다른 OCR은 호출하지 않는다.
- PDF는 PDFium `page.render(scale=2)`로 PNG로 저장한다. OCR 프로세스에는 PNG bytes만 전달하며 PDF 텍스트 추출기를 호출하지 않는다.
- 실제 문서는 공개 KDoc 데이터의 구인 공고, 기술교육 자료(안전검사), 교육운영계획 각 1 PDF 페이지이다. 마지막 파일은 인쇄면 118·119를 함께 담은 펼침면이다. 파일명은 `sources/real_sources.json`에 고정한다. 데이터셋의 OCR/LLM 기반 부분 문구 정답은 CER 정답으로 사용하지 않는다. PNG를 직접 보고 원 PDF의 디지털 텍스트를 참고하여 공백·표 순서를 수동 정리한 정답을 OCR 실행 전에 고정한다. 원 PDF 텍스트 참고 파일은 `sources/*_native_text_reference.txt`에 남기며 추론 프로세스에서는 읽지 않는다. 단일 검수자(이 평가를 수행한 에이전트)의 시각 검수이며 독립 사람 이중 검수는 아니다.
- 합성 문서는 프로젝트 소개 2개, 과목표 2개, 공모전 공고 2개이다. 원문을 먼저 JSON에 확정하고 Nanum Gothic / Nanum Myeongjo로 렌더링한다. 원본, 50% 축소, 원본 크기 Gaussian blur(radius=1.2)를 구분한다. 변형본은 새로운 원본 문서로 세지 않는다.
- 읽기 순서: 페이지 위→아래. 표는 행 우선, 행 안에서 왼쪽→오른쪽. 셀 내부는 위→아래. 셀 구분은 탭 하나, 행/시각적 본문 줄 구분은 LF 하나. 장식 도형과 선은 제외하고 글자로 인쇄된 글머리표·제목·페이지 번호·머리말·꼬리말은 포함한다. 정답 끝에 인위적 LF를 추가하지 않는다. 이 규칙은 예측 결과를 보고 바꾸지 않는다.
- 펼침면 `real_03`은 왼쪽 인쇄면 전체(118), 오른쪽 인쇄면 전체(119) 순이다. 병합 셀은 차지하는 첫 행에 한 번만 기록한다. 빈 셀은 텍스트를 만들지 않는다. 글자 사이 디자인용 자간은 실제 문자 사이 공백과 시각적으로 구분이 어려우므로 원 PDF 텍스트를 참고하며 이 불확실성은 공백 제거 CER에서 완화된다. 실제 문서의 오탈자는 교정하지 않는다.
- 정답·예측에 Unicode NFC만 적용한다. 숫자, 영문 대소문자, 문장부호를 보존한다. 공백 포함 CER과 `str.isspace()`에 해당하는 문자를 모두 제거한 CER을 각각 계산한다.
- Levenshtein 단위 비용으로 삽입 I, 삭제 D, 치환 S를 센다. 전체 CER = Σ(I+D+S)/Σ정답 문자 수. 문서 CER 평균을 전체 CER로 사용하지 않는다. 오류 정렬은 RapidFuzz editops를 사용한다.
- 전체 입력 결과와 실제/합성, 원본/변형별 합계를 모두 낸다. 주 전체 CER은 평가 입력 전체(원본+변형)의 micro CER이며, 원본만의 micro CER도 별도로 제시한다.
- 성공은 비어 있지 않은 OCR 텍스트 반환, 빈 출력은 CER 100% 삭제로 점수화한다. 실행 오류는 별도 건수로 남기고 보수적으로 빈 문자열(모든 정답 삭제)로 전체에 포함한다. 실행 성공 입력만의 CER도 함께 기록한다.
- 장치 선택은 서비스 코드 그대로 CUDA 가능 시 CUDA, 나머지는 CPU. PyTorch CPU thread는 평가 스크립트에서 2로 고정한다. 모델 생성 시간과 import 시간을 별도로 기록하고, 채점 대상과 별개의 준비 이미지 1회를 먼저 실행한다.
- 시간은 입력 PNG bytes를 준비한 뒤 `LocalOCR.extract('png', bytes)` 직전부터 텍스트 반환 직후까지 `perf_counter()`로 측정한다. PNG 디코딩, RGB 변환, 4방향 탐색, 검출, 영역 인식, 순서 정렬을 포함한다. 파일 읽기, PDF 렌더링, 정답 채점, 모델 로딩은 제외한다. 입력별 1회 측정이며 반복 실험 분산이나 서버 처리량을 의미하지 않는다.
- 모델이나 서비스 코드는 수정하지 않는다. 정답과 이미지의 SHA-256을 manifest에 기록하고 예측 실행 시 검증한다. 예측을 보고 정답/이미지를 바꾸거나 샘플을 제외하지 않는다.
