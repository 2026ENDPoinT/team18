# 진로 문장 평가

`career_goals_100.csv`는 개발·회귀 입력이며 관련 역량은 미검토 가설이다. `draft_200.csv`는 검토 전 200개 후보이고 독립적인 정답이 아니다. 목표와 관련도 라벨을 사람이 검토하기 전에는 정확도나 적합도를 산출하지 않는다.

현재 보존된 비교 실행은 `runs/20261108T054152Z-db17025d/`의 보고서·CSV·추적·요약이며 같은 모델·목록·임계값에서 기존/개선 목표 해석과 기존/두 과목 태그 후보의 네 조합을 담는다. 이 결과는 전체 과목 태깅 후보가 아닌 `tagging/sample.json`을 사용했다. 추적에는 입력 ID와 문장 위치가 들어 있으므로 접근에 주의한다.

`run_followup.py`는 동일한 구성의 새 실행을 `runs/`에 생성한다. 최신 한 묶음만 남길 때는 결과 전체를 함께 정리하고 조건별 파일을 섞지 않는다. `diagnose.py --weights '{"data_analysis":1,"statistics":1}'`는 직접 역량 주입 진단이다. `evaluate.py`는 검토 라벨이 없으면 품질 지표를 계산하지 않는다. 보조 결과는 `artifacts/`에 기록된다. 실행 방법은 모듈 README를 참고한다.
