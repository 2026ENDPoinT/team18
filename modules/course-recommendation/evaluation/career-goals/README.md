# 한국어 희망 진로 예시 100개

`career_goals_100.csv`는 평가 준비용 진로 문장과 관련 역량 가설이다. 백엔드, 프론트엔드·모바일, 데이터 분석, AI, 보안, 시스템, 소프트웨어, 복합 진로, 제외 표현, 모호·범위 밖 목표를 각 10개씩 담았다. `관련_역량_가설`의 역량은 `|`로 구분한다. 모든 역량이 직무에 필수라는 주장이나 학생의 보유·부족 능력에 대한 판단이 아니다.

모호하거나 컴퓨터공학 추천 범위 밖인 10개 문장은 근거 없는 역량을 확정하지 않고 빈 칸과 `추가 확인 필요`로 표시했다. 나머지는 `미검토 가설`이며 사람이 적합성과 복수 정답을 검토해야 한다. 부정·비교 표현의 해석도 확인해야 한다.

역량은 읽기 쉬운 한국어 표현이며 현재 모델 묶음의 skill_id와 일대일 매핑된 정답이 아니다. 없는 역량은 사전과 과목 태그를 검토해 확장해야 한다. 이 파일만으로 추천 정확도를 계산하거나 임계값을 확정하면 안 된다. 평가에 쓰기 전 문장별 정답을 검토하고 조정용과 최종 점검용 데이터를 분리해야 한다.

## 100개 목표 추천 실행

`recommendations_100.csv`는 `seoultech-test-v4` 묶음과 실제 E5 FP32 ONNX 모델을 사용한 출력이다. 각 행에 원래의 목표와 미검토 역량 가설, 추천 상태, 모델이 선택한 역량과 내부 가중치, 최대 5개 과목의 이름·임시 행 ID·내부 점수를 기록한다. 추천 과목의 태그는 과목명에서 추론한 미검토 태그이며, 이름과 점수는 실제 강의 내용이나 수강 가능 여부를 보증하지 않는다. 한영 수업은 같은 그룹으로 처리했다.

입력 문장 이외의 직무 선택은 지정하지 않았고, 선택된 이수 과목은 빈 목록이며 이수 상태는 `unconfirmed`다. 이는 실제 미이수를 확인했다는 뜻이 아니다. 사용자마다 이수 내역이나 선택 직무가 달라지면 결과도 달라진다.

이번 실행에서 `ok` 36건, `no_match` 64건이었다. 이는 정확도나 성능 수치가 아니다. 예를 들어 자연어로 된 사용자 행동 분석 목표는 `no_match`이고, 아직 프로그래밍과 보안 중 고민한다는 모호한 문장에는 추천이 생성됐다. 임시 임계값과 미완성 역량 사전 및 부정·모호 표현 처리 등을 사람의 검토 자료로 평가해야 한다. 범위 밖 목표나 모호한 목표에서 `no_match`가 항상 오류인 것은 아니다. 원본 목표별 역량 가설은 검토되지 않았으므로 이를 정답으로 삼아 정밀도를 계산하지 않았다.

모델 및 서울과기대 묶음을 위쪽 디렉터리의 안내대로 준비한 뒤 저장소 루트에서 재실행한다:

```sh
modules/course-recommendation/artifacts/.venv/bin/python modules/course-recommendation/evaluation/career-goals/run_recommendations.py
```

`recommendations_100_summary.json`에 모델 revision, 입력과 목록 SHA-256, 스냅샷과 상태 건수를 기록한다. 기존 출력 파일은 실행할 때 덮어쓴다.
